# PSD to HTML Shop Page

## Project Overview

This project involved converting a PSD design into a fully functional and responsive web page using HTML and CSS. The goal was to accurately recreate the original design while applying modern front-end development techniques such as Flexbox, CSS Grid, and media queries.

---

## Features

- Responsive page layout
- Semantic HTML structure
- Navigation bar
- Hero section
- Product categories section
- Product grid layout
- Footer section
- Mobile, tablet, and desktop support
- Media query implementation

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Visual Studio Code
